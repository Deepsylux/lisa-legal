LISA — páginas web para publicar en GitHub Pages

Sube los cuatro archivos de esta carpeta a la raíz de un repositorio GitHub:
- index.html
- privacidad.html
- condiciones.html
- LEEME.txt (opcional; puedes no publicarlo)

Después, en el repositorio, abre Settings > Pages.
En Build and deployment, elige Deploy from a branch, branch main y folder /(root), y guarda.
Espera a que GitHub Pages publique el sitio.

Las direcciones tendrán esta forma:
https://TU-USUARIO.github.io/lisa-legal/privacidad.html
https://TU-USUARIO.github.io/lisa-legal/condiciones.html

Sustituye TU-USUARIO y lisa-legal por los nombres reales que elijas.
Revisa los documentos antes de publicarlos. El repositorio y las páginas serán públicos.
No subas nunca el archivo PEM, tokens, contraseñas ni movimientos bancarios.
