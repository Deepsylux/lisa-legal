Política de privacidad de LISA

Última actualización: 22 de noviembre de 2026

LISA es una aplicación de escritorio para uso personal destinada a organizar movimientos bancarios, clasificar ingresos y gastos, elaborar presupuestos y estimar pagos recurrentes.

1. Responsable

Responsable del tratamiento: el titular particular que instala y utiliza esta copia de LISA. Contacto para cuestiones de privacidad: manueldante@hotmail.com.

LISA es un proyecto de uso personal y no ofrece en esta versión un servicio público multiusuario. Esta página es una plantilla informativa para la instancia personal de su titular.

2. Datos tratados

  • Datos de movimientos y cuentas que el usuario decida consultar o importar desde su entidad bancaria.
  • Fecha, concepto, importe, cuenta, categoría y estado de los movimientos.
  • Presupuestos, objetivos de ahorro, categorías y reglas de clasificación configuradas por el usuario.
  • Datos de gastos recurrentes previstos y notas introducidas por el usuario.

3. Finalidad y funcionamiento

Los datos se utilizan exclusivamente para mostrar movimientos, clasificarlos, calcular presupuestos, detectar patrones de gastos recurrentes y generar estadísticas para el usuario. La aplicación está diseñada para conservar los datos de trabajo en la base de datos local del dispositivo del usuario.

Cuando el usuario inicia una conexión bancaria, se intercambian con Enable Banking las solicitudes técnicas necesarias para iniciar la autorización y obtener la información de cuenta consentida. La entidad bancaria realiza el proceso de autenticación reforzada. Enable Banking actúa como proveedor de conectividad bancaria y trata los datos conforme a sus propios términos y avisos.

4. Acceso y seguridad

El usuario debe proteger su ordenador, sus copias de seguridad, el archivo de clave privada de la aplicación y cualquier token de acceso. La clave privada no debe compartirse ni enviarse por correo o mensajería. LISA no debe solicitar ni almacenar la contraseña bancaria del usuario.

La conexión se debe limitar a servicios de información de cuentas y a los permisos de solo lectura necesarios. No se deben habilitar servicios de iniciación de pagos.

5. Conservación y eliminación

Los datos locales se conservan hasta que el usuario los elimine o desinstale/borre expresamente la base de datos. El usuario puede eliminar la base de datos y las copias de seguridad bajo su control. La revocación del consentimiento bancario debe realizarse mediante los mecanismos de la entidad bancaria o del proveedor de conexión.

6. Cesiones y terceros

LISA no vende los datos personales ni los utiliza para publicidad. Para la conexión bancaria se utiliza Enable Banking; la entidad bancaria y Enable Banking pueden tratar datos conforme a sus respectivas condiciones y obligaciones. No se afirma que los datos nunca salgan del dispositivo: la autorización y consulta bancaria requieren comunicaciones con esos proveedores.

7. Derechos y consultas

Para consultas relacionadas con los datos almacenados localmente, el usuario puede gestionar directamente la base de datos de LISA. Para ejercer derechos frente a la entidad bancaria o Enable Banking, debe dirigirse al responsable correspondiente según sus avisos de privacidad.

Contacto del titular: manueldante@hotmail.com.

8. Cambios

Esta política puede actualizarse si cambian las funciones, la arquitectura o los proveedores de LISA. La fecha de actualización se indicará al principio del documento.

Aviso: este texto es un borrador informativo para una aplicación personal. Antes de publicarlo como política legal definitiva, el titular debe completar el contacto y comprobar que describe exactamente la versión y la arquitectura que utiliza.
